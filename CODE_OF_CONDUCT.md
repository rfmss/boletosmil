# Código de conduta

Este projeto busca um ambiente respeitoso, acessível e colaborativo.

São esperados:

- respeito a diferentes níveis de experiência;
- crítica técnica dirigida ao trabalho, não à pessoa;
- cuidado com privacidade e exposição involuntária;
- linguagem inclusiva e objetiva;
- disposição para corrigir erros.

Assédio, discriminação, intimidação, publicação de dados pessoais e ataques pessoais não serão tolerados. Incidentes devem ser comunicados pelos canais privados do repositório.
