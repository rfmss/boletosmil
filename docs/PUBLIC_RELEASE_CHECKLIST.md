# Checklist de publicação pública

## Privacidade

- [ ] `npm run privacy` aprovado.
- [ ] Nenhum documento, backup ou screenshot real.
- [ ] Nenhum nome, endereço, conta, contrato ou credencial real.
- [ ] Nenhuma chave de assinatura ou arquivo de ambiente.
- [ ] Dados demonstrativos evidentemente fictícios.
- [ ] Histórico da branch pública revisado.

## Produto

- [ ] Criar, pagar, reabrir e excluir conta.
- [ ] Gerar sequência atravessando o ano.
- [ ] Adicionar parcelamento e validar aviso de encerramento.
- [ ] Exportar e restaurar backup.
- [ ] Limpar dados locais.
- [ ] Usar modo guiado.
- [ ] Reabrir offline após primeiro carregamento.

## Qualidade

- [ ] `npm test` aprovado.
- [ ] `npm run build` aprovado.
- [ ] Navegação por teclado.
- [ ] Contraste e zoom a 200%.
- [ ] Celular em retrato e paisagem.
- [ ] Firefox e Chromium.
- [ ] Service worker sem erros no console.

## Documentação

- [ ] README atualizado.
- [ ] Política de privacidade atualizada.
- [ ] Limitações de segurança declaradas.
- [ ] Modelo de dados compatível.
- [ ] Roadmap sem promessas não planejadas.
